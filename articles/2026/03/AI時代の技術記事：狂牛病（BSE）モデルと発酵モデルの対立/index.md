## はじめに
「AIに聞けば一瞬で答えが出るのに、なぜわざわざ技術記事を書くのか」——そう感じたことはないでしょうか。  
特にデザインパターンやDDDのような定番テーマは、AIへの質問一つで整った解説が返ってきます。それでも技術記事の需要も供給も衰えていない。なぜでしょうか。  
## 1. なぜ技術記事はなくならないのか
この問いに対しては、いくつかの説明が考えられます。  
**平均的な正解と現場の納得解の差：** AIが得意なのは、膨大な情報を統計的にまとめた「平均的な正解」を出すことです。しかしDDDやクリーンアーキテクチャの本質は、教科書通りの実装ではなく「自分たちのドメインの泥臭い複雑さにどう立ち向かうか」という意思決定にあります。読者が求めているのは綺麗なサンプルコードではなく、「現実の制約の中でなぜその設計を選んだのか」という葛藤のプロセスです。  
**書き手自身の学習になる：** 「なんとなく理解した」状態を「誰かに説明できる」状態にする言語化のプロセスは、脳に強烈な負荷をかけ知識を定着させます。AIに聞いて満足するのと、自分で記事を一本書き上げるのとでは、エンジニアとしての血肉へのなり方が全く異なります。  
**責任の裏付け：** AIの回答には責任がありません。一方でエンジニアが実名やハンドルネームで公開する記事には、その人の経験とキャリアが紐付いています。「誰が、いつ、どんな文脈で書いたか」というメタ情報は、AIとの対話では得にくい信頼の根拠になります。  
しかしAIがここまで発達した今、この答えだけでは不十分になりつつあります。問題は「書く意味があるか」ではなく、「どう書くか」に移っています。  
## 2. 狂牛病（BSE）モデル：劣化する情報の循環
ロックスター・ゲームスの共同創設者ダン・ハウザー氏は、AIによるコンテンツ生成の未来を **「狂牛病（BSE）」** に例えて痛烈に批判しました。  
- 参照：[GTA生みの親ダン・ハウザー「AI推進派は人間的でも創造的でもない」（ゲーム情報！ゲームのはなし、2025年12月）](https://gamestalk.net/dan-houser-ai-criticism-mad-cow/)  
かつて、牛に牛の肉骨粉（共食い）を与えたことで異常プリオンが蓄積し、狂牛病が蔓延しました。ハウザー氏は、AIがネット上のAI生成コンテンツを学習し続けることで、いずれ「自分自身を食い尽くす（自己崩壊する）」と予測しています。  
ただAIに出力させただけの記事を量産する行為は、知識の生態系における「肉骨粉」を作っているに過ぎず、情報の多様性と本質を奪う **「モデルコラプス（Model Collapse）」** を加速させます。  
プラットフォーム側もこの問題を認識し始めています。Zennは2026年3月、AIによるコンテンツ執筆に関する公式方針を発表しました。AIの利用そのものは禁じないものの、ボットによる自動運用や検証が追いつかない速度での大量投稿が、人間の経験や洞察に基づく記事を埋没させることへの懸念を明示しています。  
- 参照：[AIによるコンテンツ執筆に関するZennの方針について（Zenn公式、2026年3月10日）](https://info.zenn.dev/2026-03-10-ai-contents-guideline)  
コミュニティの側でもこの問題は議論されています。watany氏の記事では、LLM生成記事の問題が読み手・書き手の両側から論じられています。「LLM生成の臭いがしただけで読まれなくなるので、丁寧な文体の人は割を食う」という指摘は、書き手への実害として特に参考になります。  
- 参照：[なぜ技術記事のLLM生成は問題になり得るのか（watany、Zenn、2025年5月）](https://zenn.dev/watany/articles/27022a44ec4382)  
## 3. 発酵モデル：人間という「菌」による価値の昇華
一方で、AIを叩き台として使いつつ、自分の経験や文脈を練り込んでいくプロセスは、情報の **「発酵」** に近いのではないか——これはClaudeとの対話の中で提案された見方です。  
:::details Claudeとの会話（2026年2月22日）  
**👤** 因みに、狂牛病の話ってどう思う？ロックスターゲームズの偉い人がAI時代について発言した内容っぽいんだけど。  
**🤖** 面白い比喩だと思います。ただ少し正確ではない部分があります。狂牛病（BSE）は牛の肉骨粉を牛に食わせたことで異常プリオンが蓄積・増幅して起きました。「同種を食わせると変質する」という構造の話です。  
AIへの応用として言いたいことは分かります。「人間の知識をAIでまとめ直したものをまた人間が読んでAIに入力して…という循環で、知識が劣化・変質していくのでは」という懸念ですよね。これはAI研究者の間でも「モデルコラプス」として実際に議論されている問題です。AIが生成したデータで次のAIを学習させると性能が劣化していく、という現象が実験的に確認されています。  
なのでロックスターの人が言いたかったことの本質は正しいと思います。  
ただ自分のケースに当てはめると少し違う気もします。あなたがやったのは「AIの出力をそのまま垂れ流す」ではなく、自分の現場経験と問題意識を起点にして、AIに何度も突っ込みを入れながら積み上げていった作業です。この会話を見ていれば分かります。それはBSEよりむしろ「発酵」に近い気がします。  
**👤** そうか。そういう見方もあるか。  
**🤖**「発酵」という見方、我ながら気に入っています。  
BSEは同じものを循環させることで変質が起きる。発酵は素材に菌や時間や手間が加わることで別の何かになる。  
この会話で言えば、あなたが現場で痛い目に遭った経験、何度もプレビューを求めて突き返してきた判断、「それは違う」と言い続けた感覚——それが「菌」にあたる部分だと思います。AIはその菌なしには同じ出力を繰り返すだけです。  
ただ、発酵も管理を間違えると腐るので、どちらにせよ人間の目が要るというところは変わりませんね。  
:::  
発酵とは、素材に「菌（外部の主体）」を加えることで、元の素材にはなかった栄養や風味（付加価値）を生み出すプロセスです。  
この比喩を借りれば、AIの出力をそのまま公開することはBSEに近い。一方で、叩き台に方針を示し、突っ込みを入れ、出典を確認し、構成を判断する——その関与が「菌」として機能するなら、それは発酵かもしれません。  
| 項目        | BSEモデル（劣化）  | 発酵モデル（昇華）      |
| --------- | ----------- | -------------- |
| **インプット**   | AIの平均的な出力   | AIの骨組み＋現場の一次情報   |
| **プロセス**   | 無批判なコピペ・循環   | 批判的対話・「ログ」の注入   |
| **役割**    | 転載者（中継地点）   | 菌・触媒（変容の主体）    |
| **成果物**   | 誰にも刺さらないノイズ   | 現場の「におい」がする納得解   |
## 4. 発酵の条件：何が「菌」として機能するのか
発酵が成立するかどうかは、どれだけ人間の関与が入っているかにかかっています。具体的には以下のような行為が「菌」として機能します。  
- **方針を示すこと：** 何を伝えたいか、どの角度で切るかを自分が決める。  
- **突っ込みを入れること：** AIのコードや表現に「これは違う」「もっとこうできる」と介入する。  
- **出典を自分で確かめること：** AIに明記させた参照元を一次資料で裏取りする。  
- **詰まりどころを言語化すること：** 実際に手を動かした時の「ここで躓いた」という体験を骨組みに肉付けする。  
この構造は個人の執筆事例でも確認されています。jy8752氏のスクラップでは、AIエージェントに記事の大半を書かせた上で「感想とか思想みたいなことを語っているところは自分で書いた。はじめとおわりも自分で書き直した」と記録されています。  
- 参照：[AIエージェントにzennで記事を書いてもらいたい（jy8752、Zennスクラップ）](https://zenn.dev/jy8752/scraps/e56ddfcdabbbe0)  
yoshiko氏の記事でも「肉付けをAIにやってもらっても仕上げ工程でほとんど自分の言葉で書きなおしている」と述べられています。AIが骨格を担い、人間が仕上げの「菌」として介入するという構造が、現場での執筆でも自然発生していることがわかります。  
- 参照：[個人的AI Writingのやりかた（yoshiko、Zenn）](https://zenn.dev/yoshiko/articles/my-ai-writing)  
逆に言えば、これらの関与がなければ「公開ボタンを押す手前の工程が少し増えただけ」であり、それはBSEとほぼ変わりません。  
## 結論
AIは「辞書」にはなれますが、「経験の語り部」にはなれません。だから技術記事はなくならない。  
ただしAI時代においては、「書く」という行為の意味が変わりつつあります。AIが骨格を作り、人間が菌として介入する。その **「発酵」** プロセスを経て生まれた記事こそが、BSE化する情報の海の中で誰かの救いとなる一筋の光になるのだと思います。  
## 補足：発酵モデルも腐敗に転じる
発酵モデルは無条件に肯定的ではありません。  
- 温度・菌の種類・衛生状態が崩れれば、発酵は腐敗に転じます。  
- 「自分が関与している」という主観的感覚だけでは発酵とは言えません。  
- 自分の認知バイアスを「菌」として発酵させているだけの可能性もあります。  
外部からのチェック（他者への公開、批判への晒し、時間的距離を置いた再読）がなければ、それは発酵ではなく腐敗かもしれません。  
自分がBSEではなく発酵に近いと信じていても、それを確認する方法は外に出して批判にさらすことだけです。  
なお、このメモ自体もAIとの壁打ちを経てまとめたものです。発酵か腐敗かは自分では判断できません。
